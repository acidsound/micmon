# MicMon — 실시간 음정·볼륨 모니터

WebAudio API로 마이크 입력을 실시간 분석해 **음정(Pitch)** 과 **볼륨(Volume)** 을
나란한 두 개의 그래프로 모니터하는 웹 앱입니다.

## 기능

- **Record 시작 버튼** 한 번으로 실시간 모니터 시작/정지
- **공통 시간축** (가로축): 두 그래프가 같은 시간 윈도우를 공유하며 스크롤
- **음정 그래프 (왼쪽)**
  - 세로축: 피아노 건반 기준 그리드 (C2–C6, 반음 단위, 검은 건반 밴드 + C 라벨)
  - **스크롤/줌**: 드래그로 세로 스크롤, 휠/핀치·슬라이더·+/− 버튼으로 줌 (12반음 한 옥타브까지 확대), 더블클릭/전체 버튼으로 전체 보기, 스크롤바 드래그, 🎯 따라가기 모드
  - 선 색상: **볼륨** — 작으면 파랑, 크면 빨강
- **볼륨 그래프 (오른쪽)**
  - 세로축: 볼륨 dBFS (-60 ~ 0 dB)
  - 선 색상: **음정** — 낮으면 파랑, 높으면 빨강
- 현재 음정(음표명)·주파수·볼륨·튠(cents) 게이지 표시
- 시간 윈도우(5–20초)·스무딩·감도 조절
- 마이크가 없을 경우를 위한 **데모 모드** (합성 음성 신호)

## 실행 방법

정적 파일이므로 아무 웹 서버로 서빙하면 됩니다.

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# http://localhost:8000 접속
```

> 마이크(`getUserMedia`)는 보안 컨텍스트(HTTPS 또는 localhost)에서만 동작합니다.

## 기술

- `getUserMedia` + `AnalyserNode` (Float32 시간 영역 데이터)
- 음정 검출: 자기상관(Autocorrelation) + 포물선 보간
- 볼륨: RMS → dBFS 변환
- Canvas 2D 렌더링 (DevicePixelRatio 대응, requestAnimationFrame)
